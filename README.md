# Orbit Scientific Calculator

A responsive, keyboard-friendly scientific calculator that runs in any modern browser without a build step or external runtime dependencies.

## Features

- Switch between Calculator and Converter workspaces
- Arithmetic, powers, modulo, factorials, and parentheses
- Trigonometric and inverse trigonometric functions, square root, absolute value, and logarithms
- Degree and radian angle modes
- Pi, Euler's number, and the previous answer (`Ans`)
- Live result preview, calculation history, and light/dark themes
- Converters for currency, length, mass, time, area, discount, volume, number systems, speed, temperature, BMI, and GST
- Traditional and customary options including paisa, gaj, cubit, tola, seer, maund, ghadi, muhurta, regional bigha references, Roman numerals, and US/Imperial BMI inputs
- Live currency reference rates from the European Central Bank via Frankfurter (requires an internet connection)
- Keyboard support: type an expression, press `Enter` to calculate, `Backspace` to edit, or `Escape` to clear

## Run

Open `index.html` in a modern web browser. No installation or build tools are required.

The original command-line simple-interest calculator is still available in [`simple-interest.sh`](./simple-interest.sh).
